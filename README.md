# LLM → SQL → Answer

Тестовый проект: простой pipeline и интерфейс телеграм бота, который принимает текстовый вопрос пользователя, преобразует его в SQL-запрос к БД с помощью LLM, получает данные и формирует корректный ответ **без галлюцинаций**.

Отвечает только на запросы про аэрогрили.

_На самом деле реализовать RAG было бы интереснее.._

---

## 🚧 Осознанные ограничения

* нет RAG (имеем структурированные данные = нет смысла)
* нет сложной схемы БД
* Качества ответов сильно не тюнились т.к. это тестовый проект

## 🗄 Структура данных

Источник данных — CSV-файл с характеристиками устройств.

При инициализации:

* данные нормализуются (числа, цвета, программы)
* создаётся SQLite БД
* CSV → SQLite

**SQLite используется как простая, прозрачная и легко дебажимая БД.**

## 🗄 Инициализация базы данных (Один раз)

Из CSV создаётся и наполняется SQLite БД.

```bash
python data/init_db.py
```

Что делает скрипт:

* читает `data/table.csv`
* очищает и нормализует данные
* создаёт `data/products.db`
* печатает содержимое таблицы в терминал

Скрипт можно запускать повторно — он идемпотентный.

_Вы можете свободно поменять таблицу и обновить данные этим файлом._

## ⚙️ Установка

### 1. Инициализировать БД

### 2. Создать `.env` файл:

```env
OPENAI_API_KEY=your_api_key
TELEGRAM_BOT_TOKEN=your_telegram_token
OPENAI_MODEL=gpt-4.1-mini
LOG_LEVEL=INFO
```

### 3. Сборка Docker образа:
```bash
docker build -t telegram-llm-bot .
```

### 4. Запуск Docker контейнера:

```bash
docker run --env-file .env -p 8080:8080 telegram-llm-bot
```

## 🧪 Тестирование

Тесты — это **интеграционный прогон** реальных пользовательских вопросов через всю цепочку:

```bash
python run_tests.py
```

_Тест кейсы описаны в файле [run_tests.py](run_tests.py) и вы можете его редактировать._

Что происходит:

* список текстовых вопросов
* LLM генерирует SQL
* SQL выполняется
* данные анализируются
* LLM формирует финальный ответ
* результаты сохраняются в `test_results.csv`

Формат результатов:

* вопрос
* сгенерированный SQL
* результат SQL запроса
* итоговый ответ
* ошибка (если была)
